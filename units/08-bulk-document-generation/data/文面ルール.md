# 更新案内 文面ルール

## 必ず守ること
1. 値上げがある契約（値上げ率 > 0）では、**理由を1文で必ず添える**。黙って金額だけ変えない。
2. 値上げ率が 5% を超える契約は、文面の最後に
   「事前にお電話でご説明のお時間をいただけますと幸いです。」を追加する。
3. 利用状況スコアが 60 未満の顧客には、値上げの案内より先に
   **定着支援の提案を1段落入れる**（金額の話から始めない）。
4. 解約リスク「高」の顧客には値上げ案内を送らない。
   代わりに「担当より個別にご連絡します」の文面に差し替え、送付管理表の備考に理由を書く。
5. エンタープライズ契約は担当役員の連名にする（役員: 営業本部長 大河内 篤）。
6. 敬称は「様」。会社名は正式名称（株式会社の位置まで一致させる）。
7. 金額は「1,234,567円（税抜）」の形式。

## 使ってはいけない表現
- 「値上げ」→「価格改定」
- 「ご了承ください」→「ご理解いただけますと幸いです」
- 「〜させていただきます」の連続使用（1通に1回まで）

## 出力
- 1社1ファイル。`output/letters/<更新日YYYYMMDD>_<会社名>_更新案内.docx`
- 併せて `output/送付管理表.xlsx` を作成し、
  会社名 / 担当者 / 更新期限 / 新年額 / 値上げ率 / 送付要否 / 特記事項 を1行ずつ記録する。
