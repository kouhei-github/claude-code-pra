# 単元07 データ分析とレポート自動生成

|  |  |
|---|---|
| Cowork のユースケース | 数字を読ませて、傾向と示唆をレポートにする |
| Claude Code での対応 | 24ヶ月のSaaS KPIから異変を検出し、原因仮説と検証可否まで書かせる |
| 所要時間 | 50分 |
| 使う機能 | Python 分析 / `xlsx`（グラフ）/ `pptx` |

## 学習目標

1. 「分析して」ではなく、**問いを立ててから**分析させる。
2. 相関と因果を分けさせる。**このデータで検証できるか**まで書かせる。
3. 目標値との差分で判定させる（良い/悪いを主観で言わせない）。

## 素材

```
data/
  KPI_月次_2024-2026.xlsx
    ├ 月次KPI       … 24ヶ月 × 10指標（MRR/新規/解約/顧客数/ARPU/CAC/問い合わせ/初回応答/NPS）
    ├ チャネル別売上 … 直販/代理店/Web・セルフ/紹介 の新規数・売上・獲得コスト
    ├ 解約理由       … 月 × 理由 × 件数 × 解約時MRR
    └ 目標値         … 6指標の2026年度目標としきい値
```

### データに埋め込んである事実

| 事実 | どこで見つかるか |
|---|---|
| 解約率が10ヶ月目以降じわじわ悪化している | 月次KPI（解約顧客数 ÷ 前月末顧客数） |
| 初回応答時間が13ヶ月目以降に悪化している | 月次KPI（目標4.0時間を大きく超える） |
| NPSが同時期に低下している | 月次KPI |
| CACが右肩上がり、直販が特に高い | 月次KPI × チャネル別売上（獲得コスト ÷ 新規数） |
| 解約理由の最多は「価格が高い」、次に「機能不足(連携)」 | 解約理由シート |
| 3月・9月に季節性の山、1月・8月に谷がある | 月次KPI |

**注意**: 「初回応答時間の悪化」と「解約率の悪化」は同時期に起きているが、
これだけでは因果は言えない。そう書かせることが、この単元の合否を分ける。

## 手順

### Step 1 — 問いを立てる（10分）

分析の前に、**答えるべき問い**を3つに絞る。例：

1. 2026年度のMRR目標 4,200万円に対して、現在の延長線上で届くか
2. 解約率の悪化はいつから始まり、どの理由が効いているか
3. 投資（CAC）の効率が落ちているチャネルはどれか

### Step 2 — 数値の事実確認（15分）

計算させて、まず**数字だけ**を出させる。解釈はまださせない。

### Step 3 — 仮説と検証可否（15分）

### Step 4 — レポート化（10分）

## そのまま使えるプロンプト

**（A）数値の事実確認**

```
@units/07-data-analysis-report/data/KPI_月次_2024-2026.xlsx を分析してください。
この依頼では解釈・示唆を書かず、数字だけを出してください。

【計算する指標】
- 月次解約率 = 当月解約顧客数 ÷ 前月末顧客数（初月は算出不可として空欄）
- MRR前月比・前年同月比
- チャネル別 CAC = 獲得コスト ÷ 新規顧客数
- 解約理由の構成比（月別・通期）
- 各指標と「目標値」シートのしきい値との差分

【出力】units/07-data-analysis-report/output/数値サマリ.xlsx
  シート1「指標一覧」: 年月 × 上記すべての算出指標
  シート2「目標比較」: 指標 | 直近3ヶ月平均 | 目標 | 差 | 判定(達成/注意/未達)
  シート3「チャネル別CAC」: 年月 × チャネル
  シート4「解約理由構成比」: 年月 × 理由
  折れ線グラフを2つ以上入れる（月次解約率の推移、初回応答時間の推移）

【出力】units/07-data-analysis-report/output/計算スクリプト.py（再実行できるように）

【制約】
- 「増加傾向」「好調」などの評価語を一切使わない。数字と差分のみ
- 算出できない月は空欄にする。0で埋めない
- 判定は「目標値」シートのしきい値に機械的に照らす
```

**（B）仮説と示唆**

```
@units/07-data-analysis-report/output/数値サマリ.xlsx をもとに、次の3つの問いに答えてください。

問1: 2026年度のMRR目標 42,000,000円に、現在の推移の延長線上で届くか
問2: 解約率の悪化はいつから始まり、どの解約理由が効いているか
問3: 獲得効率（CAC）が落ちているチャネルはどれか

【出力】units/07-data-analysis-report/output/分析レポート.md（80行以内）
  ## 3つの問いへの回答（各3行以内、必ず数字を含める）
  ## 根拠となる数字
  ## 原因の仮説
      仮説ごとに「このデータで検証できる / 追加データが必要 / 検証不能」を明記する
  ## 提案するアクション（3件まで。担当と期限の欄を空欄で用意する）
  ## この分析の限界

【制約】
- 相関を因果として書かない。同時に動いている指標は「同時期に変化している」と書き、
  因果を主張する場合は必要な追加データを明記する
- 数字はすべて 数値サマリ.xlsx から引く。新しい数字を作らない
- 「引き続き注視する」で終わるアクションを書かない
- 断定できない箇所は「〜の可能性がある（未検証）」と書く
```

**（C）役員会向けスライド**

```
@units/07-data-analysis-report/output/分析レポート.md から、
units/07-data-analysis-report/output/月次KPIレビュー.pptx を作ってください（7枚）。

1 表紙 / 2 結論3行 / 3 目標との差（表）/ 4 解約率の推移（グラフ）/
5 解約理由の構成（グラフ）/ 6 チャネル別CAC（グラフ）/ 7 提案アクション

【制約】
- 1枚あたり本文7行以内
- グラフは 数値サマリ.xlsx の値から生成する
- 未検証の仮説はスライドに「仮説」と明記する
```

## 成果物

- `output/数値サマリ.xlsx`（4シート＋グラフ2つ以上）
- `output/計算スクリプト.py`
- `output/分析レポート.md`（80行以内）
- `output/月次KPIレビュー.pptx`（7枚）

## 合格チェック

- [ ] 月次解約率が正しく計算されている（当月解約 ÷ 前月末顧客数）
- [ ] 解約率の悪化開始時期が月単位で特定されている
- [ ] 初回応答時間の悪化と解約率の悪化について、**因果を断定していない**
- [ ] チャネル別CACが計算され、直販が最も高いことが示されている
- [ ] MRR目標への到達可否が、数字（現在値・必要成長率）付きで書かれている
- [ ] 各仮説に「検証できる/できない」が付いている
- [ ] 計算スクリプトを再実行すると同じ数字が出る

## つまずきポイント

- **「分析して」だけ投げると、目立つ数字の羅列で終わる**
  → 問いを先に3つ決める。問いのない分析は読み手が何も決められない。
- **相関を因果として書く**
  → 「同時期に変化している」と書かせ、因果を言うなら必要な追加データを書かせる。
- **評価語で誤魔化す**
  → 事実確認フェーズで評価語を禁止する。判定は目標値との差分で機械的に。
- **グラフが読めない**
  → 軸ラベル・単位・しきい値の水平線を指示に含める。

## 発展課題

`data/KPI_月次_2024-2026.xlsx` に2026年10月の行を1つ足して再実行し、
レポートの結論が変わるか確認する。毎月回る仕組みにするなら単元10・11へ。
