# 経費精算規程（抜粋）2026年度版

## 1. 提出期限
当月分は翌月5営業日までに提出すること。

## 2. 勘定科目
| 科目 | 使うもの |
|---|---|
| 旅費交通費 | 電車・新幹線・タクシー・駐車場・航空券 |
| 宿泊費 | ホテル代（宿泊税を含む） |
| 交際費 | 社外の方を含む会食・手土産 |
| 会議費 | 社内のみの打合せ飲食、1人3,000円以下の社外飲食 |
| 消耗品費 | 10万円未満の事務用品・備品 |
| 図書研究費 | 業務に必要な書籍・資料 |
| 研修費 | セミナー・カンファレンス参加費 |

## 3. 上限・按分ルール
- 宿泊費は1泊 **15,000円** まで（超過分は自己負担、超過額を「自己負担額」列に記入）。
- 社外の方を含む会食は **1人あたり 10,000円** まで。参加人数を必ず記入する。
- タクシーは終電後・重量物運搬・複数人移動のいずれかに該当する場合のみ可。理由を備考へ。
- 領収書のない交通費は「実費（IC）」として区間・金額を記入すれば可。1件 1,000円以下に限る。
- **他人が立て替えた費用は自分の精算に含めない。**
- 法人カード（末尾4821）で決済済みの費用は **会社が直接支払済** のため、精算額は0円とし、
  「支払方法」を「法人カード」にして計上のみ行う。現金・私物カードのみ払い戻し対象。
- 私的利用がカード明細に混在する場合は精算対象外とし、明細から除外する。

## 4. 消費税
軽減税率(8%)対象（書籍・テイクアウト飲食など）は「税区分」列に 8% と記入。
