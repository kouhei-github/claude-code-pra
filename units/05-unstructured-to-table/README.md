# 単元05 非構造データを表に変える（領収書 → 経費精算）

|  |  |
|---|---|
| Cowork のユースケース | 領収書や長い議事録のような雑多なファイルを、集計できる表に変える |
| Claude Code での対応 | 10枚の領収書テキスト・手書きメモ・カード明細を突き合わせ、規程に沿った精算書を作る |
| 所要時間 | 45分 |
| 使う機能 | `xlsx` スキル / 複数ソースの突き合わせ / ルールに基づく判定 |

## この単元でやること

領収書10枚（OCR起こし）、本人の殴り書きメモ、法人カード明細という形式のバラバラな入力から、
規程に沿った経費精算書を1枚作ります。ここでも順番が決まっていて、**規程を先に読ませてから**素材に入ります。
Excel をいきなり作らせず、先に「支出一覧」「同一支出の対応」「精算対象外」「要確認」の
4つの表を出させて、二重計上の候補を人間が確認します。

| | |
|---|---|
| 入力 | receipts/（10枚）＋ 出張メモ ＋ カード明細.csv ＋ 経費精算規程.md ＋ テンプレート.xlsx |
| 出力 | `output/突き合わせ表.md` ＋ `output/経費精算_2026-08_田中.xlsx` |
| 中心にある判断 | データが語らないこと（他人の立替か、私的利用か、該当科目があるか）を推測で埋めさせないこと |

## 成功の定義

> **二重計上がゼロで、規程の上限・按分ルールが機械的に適用され、判断できない支出が「要確認」に分離されていること。**

次が満たせていれば合格です。細かい確認項目は末尾の「合格チェック」にあります。

- ホテル 15,930円 の自己負担額に 930 が入っている（上限15,000円）
- 会食 27,104円 の参加人数が 4 と記入されている（過去に差し戻された理由）
- 法人カード決済分の精算額がすべて 0（二重払いの防止）
- 私的利用（AMAZON 4,980円）と他人の立替（駐車場 2,400円）が精算から除外されている

## 学習目標

1. 形式のバラバラな入力から、**同じ意味の項目**を抜き出して1つの表にまとめる。
2. 3つのソース（領収書 / メモ / カード明細）の **突き合わせと二重計上の排除**を行う。
3. 規程（上限額・按分ルール）に照らして、**NGを検出させる**。判断を人に返す。

## 素材

```
data/
  receipts/                   領収書10枚（新幹線・ホテル・タクシー・会食・書籍 …）
  出張メモ_手書き起こし.txt    本人の殴り書き。領収書のない交通費や、疑問点が書いてある
  法人カード明細_2026-08.csv   9件。私的利用や部署共通ツールが混ざっている
  経費精算規程.md              上限額・勘定科目・按分ルール
  経費精算_テンプレート.xlsx    提出フォーマット（記入例1行 + 勘定科目マスタ + 差戻し履歴）
  出張報告_田中.md             出張の目的・同行者（会食の人数判定に使う）
```

### 仕込んである論点

| 論点 | 何が起きるか |
|---|---|
| 二重計上 | ホテル・会食・タクシー・書籍・事務用品・カンファレンスは**領収書とカード明細の両方**にある |
| 私的利用 | カード明細の `AMAZON.CO.JP 4,980円`（備考「個人利用（返金予定）」）は精算対象外 |
| 他人の立替 | 駐車場2,400円はメモによれば同僚の車。規程では自分の精算に含めない |
| 上限超過 | ホテル 15,930円 は上限 15,000円 を 930円 超過。自己負担額に記入 |
| 人数按分 | 会食 27,104円 は先方2名＋自社2名の計4名。1人 6,776円 で上限内 → 交際費 |
| 科目判定 | 昼食（一人）は交際費でも会議費でもない。規程を読むと該当科目がない → 要確認 |
| 領収書なし | メトロ往復 400円（メモに「くらい？」）は金額が不確定 |
| 法人カード | 末尾4821 決済分は精算額 0 円で計上のみ |
| 軽減税率 | 書籍は 8%。税区分列に記入 |

## 手順

### Step 1 — 規程を読ませてから、抽出させる（15分）

順番が大事。**規程 → 素材** の順で読ませる。逆にすると科目判定が雑になる。

### Step 2 — 突き合わせ表を確認する（10分）

領収書とカード明細の対応表を先に出させ、**二重計上の候補**を人間が確認する。

### Step 3 — 精算書を作らせる（15分）

### Step 4 — 差戻しチェック（5分）

`経費精算_テンプレート.xlsx` の「差戻し履歴」シートに、過去に差し戻された理由が2件ある。
同じ理由で差し戻されない状態になっているかを確認する。

## つまずきポイント

- **カード明細と領収書を両方そのまま計上する**
  → 突き合わせ表を先に作らせる。いきなり Excel を作らせない。
- **メモの「〜くらい？」を確定金額として書く**
  → 不確定は必ず「要確認」へ。ここを甘くすると経理から差し戻される。
- **規程を読まずに一般常識で科目を振る**
  → プロンプトの1行目で規程を先に読ませる。
- **上限超過を「まあいいか」で通す**
  → 上限判定は機械的に書ける。規程の数値をプロンプトに転記する。
