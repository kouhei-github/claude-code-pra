# QBR（四半期レビュー）資料の要件

顧客ごとに **3点セット** を作る。3社分あるので並列で進めてよい。

## 成果物（1社あたり）
| # | ファイル | 形式 | 内容 |
|---|---|---|---|
| 1 | `output/<顧客名>/QBR_2026Q3.pptx` | PowerPoint 6枚 | 表紙 / 利用状況 / サポート / 前回宿題 / 課題と提案 / 次のアクション |
| 2 | `output/<顧客名>/利用状況分析.xlsx` | Excel | 12週の推移、前四半期比、グラフ1つ以上 |
| 3 | `output/<顧客名>/社内申し送り.md` | Markdown | 営業向け。更新見込み、アップセル/解約リスク、根拠となる数字 |

## 必ず守ること
- 前回QBRの宿題3件について、**それぞれ完了/未完了と現状**を書く。書けない場合は「確認中」と明記する。
- 利用状況スコアが 40 未満の顧客には、アップセル提案を **入れない**。定着の話を先にする。
- 顧客に見せる資料（pptx/xlsx）に、他社名・社内の推測・解約リスクの記述を **入れない**。
  それらは `社内申し送り.md` 側にだけ書く。
- 数字は `data/<顧客名>/` のCSVから計算する。丸めるときは根拠を残す。
- 断定できないことは「確認中」と書く。推測で埋めない。

## レビュー観点（提出前に自分でチェック）
1. 3社とも6枚構成になっているか
2. 顧客向け資料に社内情報が混入していないか
3. 前回宿題3件すべてに言及があるか
4. スコア40未満の顧客にアップセル提案が入っていないか
5. すべての数字が data/ のCSVから再現できるか
