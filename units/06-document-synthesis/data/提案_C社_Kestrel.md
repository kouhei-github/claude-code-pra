# Kestrel Cloud CRM ご提案書

株式会社ケストレル・ジャパン / 2026年8月20日

## 1. 想定構成
- SaaS（マルチテナント）。東京リージョンのみで稼働します。
- ユーザー数 250 名想定。

## 2. 費用
| 項目 | 金額 |
|---|---|
| ライセンス（250名 / 年） | 21,000,000円 |
| 初期構築 | 4,800,000円 |
| データ移行支援 | 3,200,000円 |
| 年間サポート（平日9-18時） | ライセンスに含む |

5年総額の目安: **1億1,300万円**（ライセンス改定率は年3%を想定）

## 3. 要件への対応
- M-01 SSO: 対応（SAML 2.0 / OIDC）
- M-02 監査ログ: **標準は13ヶ月**。5年保持は外部ストレージ連携のオプション（年 180万円）で対応。
- M-03 国内保管: 対応
- M-04 移行支援: 対応。120万レコードの実績あり（過去最大 90万レコード）
- M-05 API連携: REST API 標準提供。ただし **双方向のリアルタイム同期は非対応**、
  15分間隔のバッチ同期となります。
- M-06 稼働時期: **2027年3月** を提案（1月末は要員確保が困難）
- W-01 モバイル: 対応 / W-02 ノーコード: 一部 / W-03 ダッシュボード: 対応 / W-04 24/365: 非対応

## 4. 特記事項
弊社は国内SIとの協業体制により、現場定着支援（3ヶ月）を無償で提供します。
