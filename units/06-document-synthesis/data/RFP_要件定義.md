# 顧客管理基盤リプレース RFP（社内版）

- 発行: 2026年7月1日 / 情報システム部
- 背景: 現行の Legacy CRM（2016年導入・オンプレ）が2027年3月にサポート終了。
- 対象ユーザー: 営業180名、カスタマーサクセス60名、経営企画10名。

## 必須要件（MUST）
| ID | 要件 |
|---|---|
| M-01 | SAML 2.0 による SSO（社内 IdP: Entra ID）|
| M-02 | 監査ログを 5 年間保持し、CSV でエクスポートできること |
| M-03 | 国内リージョンでのデータ保管 |
| M-04 | 既存 Legacy CRM からの移行支援（120万レコード） |
| M-05 | REST API による基幹（Factory Nexus）との双方向連携 |
| M-06 | 2027年1月末までに本番稼働 |

## 推奨要件（WANT）
| ID | 要件 |
|---|---|
| W-01 | 営業向けモバイルアプリ |
| W-02 | ノーコードでの画面カスタマイズ |
| W-03 | 予実ダッシュボードの標準提供 |
| W-04 | 日本語での24/365サポート |

## 予算
初年度 3,500万円以内、5年 TCO 1億2,000万円以内。

## 評価軸と配点
機能適合 30 / コスト 25 / 移行リスク 20 / セキュリティ 15 / サポート体制 10
